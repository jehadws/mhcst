# منصة كلية المعايير الحديثة للعلوم والتقنية (MHCST)

منصة ويب متكاملة لكلية المعايير الحديثة للعلوم والتقنية، تجمع في تطبيق واحد:

- **الموقع العام:** تعريف بالكلية، الأقسام، هيئة التدريس، المدونة، الأسئلة الشائعة، التواصل، وبوابة بحث للطلاب.
- **التقديم والقبول:** نموذج تسجيل للطلاب الجدد (مع حفظ تلقائي للمسودة) وصفحة «طلبي» لمتابعة حالة الطلب، وقائمة مراجعة للإدارة (قبول / رفض / قيد المراجعة).
- **النظام الأكاديمي:** الأقسام، الصفوف، المواد، الطلاب، التسجيلات، الجدول الدراسي، الحضور، الدرجات، التقارير، سجل التدقيق.
- **بوابة الطالب:** الفصل الحالي، المواد، الجدول، الدرجات، تسجيل المواد ذاتياً، وكشف الدرجات (PDF).
- **إدارة المحتوى والتواصل:** المقالات، اللافتات، الآراء، الأسئلة الشائعة، رسائل التواصل، النشرة البريدية، قوالب الإشعارات.

الواجهة بالعربية (من اليمين إلى اليسار) مع دعم الإنجليزية، ووضع فاتح وداكن.

## التشغيل المحلي (التطوير)

```bash
# 1. استنساخ المشروع
git clone https://github.com/jehadws/mhcst.git
cd mhcst

# 2. تثبيت الحزم
composer install
npm install

# 3. ملف البيئة
cp .env.example .env
php artisan key:generate

# 4. قاعدة البيانات (SQLite افتراضياً في .env.example)
touch database/database.sqlite
php artisan migrate --seed

# 5. التشغيل (الخادم + الطابور + Vite معاً)
composer run dev
```

بعد التشغيل افتح العنوان الذي يعرضه `php artisan serve` (عادةً `http://127.0.0.1:8000`).

> **تنبيه:** أمر `--seed` يضيف **بيانات تجريبية** (طلاب وأساتذة ومقالات وحسابات اختبار). استخدمه في بيئة التطوير فقط، ولا تشغّله على خادم الإنتاج.

### حسابات الدخول التجريبية

تُنشأ حسابات الإدارة من `database/seeders/UserSeeder.php` بالبريد `admin@mhcst.edu.ly` و`manager@mhcst.edu.ly` و`editor@mhcst.edu.ly` و`support@mhcst.edu.ly`. كلمة المرور تؤخذ من المتغير `SEEDER_DEFAULT_PASSWORD` في `.env` إن وُجد، وإلا تُستخدم قيمة افتراضية للتطوير. حسابات الأساتذة والطلاب التجريبية يضيفها `CmsDemoDataSeeder`.

```bash

```

## متغيرات البيئة المهمة

| المتغير | الغرض |
|---|---|
| `APP_ENV`، `APP_DEBUG` | في الإنتاج: `production` و`false` |
| `APP_URL` | رابط الموقع الفعلي |
| `APP_TIMEZONE` | المنطقة الزمنية (مثل `Africa/Tripoli`) |
| `DB_*` | بيانات قاعدة البيانات |
| `MAIL_*` | إعدادات البريد الصادر |
| `QUEUE_CONNECTION` | `database` افتراضياً |
| `AUTH_REGISTRATION_ENABLED` | `false`: التسجيل العام معطّل، والطلاب يقدّمون عبر مسار التقديم |
| `DEPLOY_TOKEN` | رمز سري لمسار النشر بعد الرفع |
| `SEEDER_DEFAULT_PASSWORD` | كلمة مرور الحسابات الأولية (مطلوبة في الإنتاج عند تشغيل `UserSeeder`) |
| `BACKUP_FAILURE_EMAIL` | بريد إشعارات فشل النسخ الاحتياطي |

القائمة الكاملة في الملف `.env.example`.

## النشر

يُنشر المشروع على استضافة مشتركة (cPanel). التفاصيل الكاملة (الإعداد، النشر الآلي والمستمر، النسخ الاحتياطي والاستعادة، حل المشكلات) في وثيقة **«دليل النشر والتشغيل»**، وملف `deploy.md` يحتوي ملخصاً أقدم للمراجع.

## المساهمة

1. أنشئ فرعاً جديداً من `develop`.
2. اتبع أنماط الكود الموجودة، وراجع الملفات المجاورة قبل إضافة أي ملف جديد.
3. استخدم متغيرات التصميم المعرّفة (لا ألوان أو قيماً عشوائية) حسب `DESIGN.md`.
4. أضف اختباراً لكل سلوك جديد، وشغّل `php artisan test --compact` و`vendor/bin/pint` قبل الدفع.
5. افتح طلب دمج (Pull Request) إلى `develop`.
